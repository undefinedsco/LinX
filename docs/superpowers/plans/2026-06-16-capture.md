# Capture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first Capture foundation: shared Pod models for capture candidates/events and a Secretary capture skill that uses those models with Approval/Input boundaries.

**Architecture:** `@undefineds.co/models` owns durable `CaptureCandidate` and `CaptureEvent` resources, descriptors, vocab, and repository helpers. LinX CLI packages a `capture` Secretary skill and exposes it beside `basic`, `symphony`, and `xpod-cli`; xpod remains the Pod IO surface and does not classify capture semantics.

**Tech Stack:** TypeScript, `@undefineds.co/drizzle-solid`, `@undefineds.co/models`, LinX product skills, Node test runner, Vitest.
