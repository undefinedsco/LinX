# Module Spec: Inbox / Approval

## 目标

Inbox 是全局异常中心，收口待审批、待认证、异步完成通知。当前会话内的审批优先在 Chat inline 处理。

## 范围

- 右上角通知入口。
- Inbox popover 或 sheet。
- 待审批列表。
- 待认证列表。
- 异步完成通知。
- 审批详情。
- Chat inline card 共享同一对象。

## 不做

- 不作为一级主导航常驻。
- 不复制 Chat 里的审批数据。
- 不把 Audit 做成用户必须先理解的页面。

## 分类

| 分类 | 例子 | 入口 |
| --- | --- | --- |
| 待审批 | 写文件、访问外部网络、执行命令 | Chat inline + Inbox |
| 待认证 | OAuth、工具登录、本地服务授权 | Inbox |
| 通知 | 任务完成、同步完成、失败重试 | Inbox |

## Chat 与 Inbox 关系

同一个 approval item：

- 在当前 Chat 中显示 inline card。
- 在 Inbox 中显示汇总项。
- 处理后两处同时更新。

## 审批卡片字段

- 动作标题。
- 请求来源。
- 风险说明。
- 目标资源。
- 按钮：批准、拒绝、查看详情。

## 自动审批策略

首屏不暴露复杂策略。未来在会话设置或全局设置里提供：

- 手动确认。
- 安全操作自动通过。
- 当前容器内自动通过。

高风险操作始终手动。

## 验收

- 当前会话审批不强迫用户跳页。
- Inbox 能看到所有待处理项。
- 处理一个审批后 Chat 和 Inbox 状态一致。
- 无待处理项时通知入口低噪音。
