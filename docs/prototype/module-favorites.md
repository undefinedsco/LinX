# Module Spec: Favorites

## 目标

Favorites 是可重入的记忆索引，不是纯快照列表。

## 范围

- 收藏消息。
- 收藏文件。
- 收藏链接。
- 收藏联系人/Agent。
- 收藏搜索和筛选。
- 回到原对象。

## 不做

- 不把收藏内容复制成新对象。
- 不展示无法回跳的死快照。
- 不用 Favorites 替代 Files 或 Chat。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 标题 | 对象标题或摘要 |
| 类型 | message/file/link/contact/agent |
| 来源 | chat/thread/message |
| 时间 | 收藏时间 |
| 摘要 | 可检索文本 |

## 主操作

- 打开。
- 回到来源。
- 取消收藏。
- 复制链接/URI。

## 回跳规则

| 收藏类型 | 回跳目标 |
| --- | --- |
| 消息 | Chat 模块，定位原消息 |
| 文件 | Files 详情，保留来源聊天入口 |
| 链接 | Chat 原消息或链接详情 |
| 联系人 | Contacts 详情 |
| Agent | Contacts 详情或 Chat |

## 数据边界

- Favorite 只保存索引和引用，不复制完整业务对象。
- 源对象删除或无权限时，收藏项显示失效状态。

## 验收

- 收藏消息能回到原消息。
- 收藏文件能回到文件详情和来源聊天。
- 失效收藏不崩溃。
- 没有收藏时显示空状态。
