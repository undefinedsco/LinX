# Module Spec: Favorites / 已收藏

状态：R6 目标设计，2026-09-28。对应 LS-04、12；[联合体验 Spec](../../../homepage/docs/specs/personal-ai-product-experience-r6.md)。

## 目标与入口

收藏是用户主动标记的重入引用索引。它位于知识页固定“已收藏”视图；工作中的收藏操作、全局搜索和旧深链保持可用。收藏不是知识确认、自动记忆或训练材料授权。

## 范围与信息

支持消息、文件、链接、人和 Agent 的现有引用；保留搜索与类型筛选。列表显示标题/摘要、类型、原来源、收藏时间和可访问状态。来源缺失不能用无依据的自动摘要补齐。

主操作为打开、回到来源、取消收藏、复制有权限分享的链接/URI。取消收藏只移除该引用，不删除源文件/消息、已确认知识或模型材料。

| 原对象 | 打开位置 |
|---|---|
| 消息 | 工作中的原会话与消息定位 |
| 文件/知识资源 | 知识中的原对象，保留来源工作入口 |
| 链接 | 原消息或对应链接详情 |
| 人/群组/Agent | 工作中的协作对象详情；Agent 方法另转我的 AI |

## 三种独立决定

1. 收藏：以后找回。
2. 确认知识：核对来源、条件和修订后，按知识合同保留。
3. 纳入训练：按训练用途、材料版本和授权合同选择。

收藏操作不勾选后两项。可以从收藏打开来源并进入既有知识流程或材料选择面，不能在星标按钮背后直接触发确认、训练或模型更新。取消收藏也不暗示模型已遗忘。

## 来源状态与恢复

| 状态 | 展示与可用操作 |
|---|---|
| 可访问 | 打开原对象/来源，返回保持筛选与位置 |
| 明确已删除 | 标明源已删除，可移除收藏；不自动重建源 |
| 权限不足/撤权 | 标明无法访问并提供已有申请/修复入口；不误报删除 |
| 离线/暂不可达 | 保留引用，显示连接状态，可重试；不据此判定源不存在 |
| 来源有修订 | 展示引用版本与当前版本差异入口；不无提示替换当时依据 |

历史摘要或快照只有在现有权限与缓存合同允许时才可展示；不得用快照绕过撤权。修复返回同一引用，核对身份和来源版本，不复制一份新业务对象。

## 数据边界与验收

Favorite 保存引用和索引，不成为第二份源数据或知识真相。引用身份由共享模型定义；新界面不改历史 ID/URI。

- 原消息、文件、联系人/Agent 的收藏能经新入口和旧深链定位同一对象。
- 用户只收藏或取消收藏时，知识确认状态、训练授权和源对象均不改变。
- 删除、撤权、离线、修订四种状态可区分；无数据有正常空状态。
- 同身份空间恢复列表位置；换身份不显示旧收藏/摘要。
- 长标题可阅读，键盘可完成筛选、打开、回到来源和取消收藏。
