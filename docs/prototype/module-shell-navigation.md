# Module Spec: Shell / Navigation

状态：R6 目标设计，2026-09-28；不代表当前实现。权威：[联合体验 Spec R6](../../../homepage/docs/specs/personal-ai-product-experience-r6.md)。对应 LS-01、02、07、09、11、12、13。

## 目标与边界

Shell 让用户稳定重入工作、知识和自己的 AI。它组织模块与身份上下文，提供通用布局插槽，不创建业务资源，不实现知识编辑器、训练表单或权限政策。`DESIGN.md` 是视觉与交互的上位规范；微信只作为信息密度参考，不作为品牌皮肤。

## 一级与常驻入口

| 入口 | 承载内容 | 次级入口 |
|---|---|---|
| 工作 | 人际与 AI 会话、项目上下文、长任务、结果 | 会话视图、协作对象、当前工作资料与成果 |
| 知识 | 资料、来源、已确认知识与待整理内容 | 文件浏览、已收藏、来自工作 |
| 我的 AI | 默认方法与能力边界、个人模型、材料与评估 | Agent 的方法详情、模型版本与使用范围 |

- 工作页固定保留“会话”和“协作对象”文字入口；工作中的纯人际会话和群组不要求创建 Task、Issue 或工作容器；人/群组/Agent 在列表中可辨识。
- 联系人保留工作页固定文字入口“协作对象”，从一级入口起最多两次操作可到完整通讯录；新建会话、参与者选择和搜索也可达。
- 收藏保留知识页固定“已收藏”入口；当前对象的收藏和回到来源不随导航迁移消失。
- Inbox 是全局待处理入口，图标有可读名称与数量；复杂审批进入完整内容区，不困在 popover。
- 全局菜单/头像提供个人资料、设置、AI 连接、服务状态、关于。AI 连接管理提供方和凭据；个人模型属于“我的 AI”。
- 聊天文件进入工作“资料与成果”或知识“来自工作”视图；旧底部入口可作迁移快捷方式，不造第二份资料库。

## 启动与重入

| 情况 | 目标行为 |
|---|---|
| 未登录 | 显示紧凑登录；不展示上个身份的业务内容 |
| 恢复身份中 | 轻量恢复状态；不抢先显示选供应商，也不载入未经核对的旧内容 |
| 首次登录、没有上下文 | 进入工作，可发起人际或 AI 会话；不要求先训练 |
| 返回用户 | 在身份和空间校验后恢复上次合法模块、对象、筛选、阅读/编辑位置；不能每次强制 Chat |
| 原对象无权限、离线、删除 | 分别说明原因，保留合法返回点；不自动改成新任务或别的账号 |
| Pod/助手/连接仅部分就绪 | 显示对应能力状态与修复入口；只阻断依赖它的操作，不谎报全局已就绪 |
| 没有个人模型 | 我的 AI 显示方法和获准知识使用，说明尚无个人模型；不展示空分数或催训练告警 |

具体初始化事实见[登录规范](../login-modal-local-binding-spec.md)；草稿、退出和切换见[设置规范](module-profile-settings.md)。合法上下文校验失败时返回所属模块的安全列表，并解释原因。

## 旧入口迁移

这是产品标签与入口迁移，不是资源迁移。路由实施负责人必须交付当前真实路由到目标视图的映射，保留资源 ID/URI、引用与授权检查；本文不发明新 URL。

| 旧入口/深链 | 新位置 | 必须保留 |
|---|---|---|
| Chat / 原会话或消息 | 工作的同一会话/消息 | 人际/群组身份、未读、置顶、搜索定位、滚动与草稿 |
| Contacts / 人、群组、Agent | 工作→协作对象；Agent 方法可转我的 AI | 原关系对象、发消息、已有会话、备注 |
| Files / 原文件、资源、来源 | 知识→同一对象 | 文件身份、路径、权限、来源与修订 |
| Favorites / 原收藏 | 知识→已收藏→原引用 | 收藏时间、来源定位、取消收藏语义 |
| 模型设置 / 凭据 | AI 连接 | 共享配置引用；不能误跳到个人模型 |

工作中的方法、候选与评估快捷入口，和“我的 AI”必须打开同一资源与草稿。跨 Xpod 修复携带对象/版本/目的/合法返回点；不把秘密或资料正文放进导航参数。返回后重读事实，不自动重复提交副作用。

## 按任务选择列数

默认是导航加内容。仅需切换真实对象集合时增加列表，详情由用户或当前任务按需打开。宽屏也不保留空第三栏。

| 页型 | 宽窗 | 窄窗 |
|---|---|---|
| 会话 | 导航、可选会话列表、会话；相关成果按需展开 | 当前会话优先，列表与详情由明确入口切换 |
| 来源/知识 | 可选资源列表、可读正文、按需来源比较 | 单一阅读面，返回保持位置 |
| 方法 | 完整编辑区、范围、保存/放弃 | 不缩成聊天气泡，不嵌套抽屉 |
| 材料/评估/模型 | 主区清单或对照；导航可收起 | 顺序阅读和选择，保留比较对象与决定 |

在 1440、1180、768、390 CSS px 及 200% 文字下检查页型；断点不能替代内容宽度预算。内容不足宽时先收可选列表/详情，再切单面；保留可见导航调用与返回。长正文自然滚动，避免多层滚动争抢。

Files 在 compact width 下隐藏全局 rail 和通用 content head，仅保留自己的约 44–48px head；文件树从抽屉按需打开，资源选择后收起。Shell 通过 `compactNavigation` 插槽提供一个模块切换入口，不叠加第二条 head；抽屉始终以可读展开态出现，不继承桌面折叠 rail 的 56px 图标状态。

## 公共交互与数据边界

- 一级入口默认有文字；紧凑图标模式仍有可读名称、键盘焦点、当前选中标记，不能只变紫色。
- 弹层支持焦点进入、约束与返回；Esc 关闭可关闭层，未保存内容走保存/放弃/继续编辑。
- Shell 仅消费身份/空间、模块/对象引用、合法恢复结果和全局待处理摘要；业务状态由模块和共享 use-case 提供。
- 导航状态是 UI 状态，不是 Task 状态。切页/关抽屉/退出应用不等于停止运行。

`聊天文件` 是 registry 声明的定向快捷入口，Shell 只转发通用 navigation intent。

Files 的 `chat-files` entry scope 由 router/composition root 解释；`PrimaryLayout` 不导入 Files store、route type 或查询逻辑。模块自己的 compact 控件通过通用 render slot 注入，不把业务组件硬编码进 Shell。

## 验收

1. 三个一级入口稳定可见；从任意页面可找到我的 AI，仍能两步内进入协作对象和已收藏。
2. 私聊、群组、AI 会话旧深链均定位原对象；不会为纯交流强制创建 Task。
3. 首次未训练可工作；返回用户恢复知识/方法/会话等上次合法上下文。
4. 会话→成果/来源/评估→返回，选中、滚动和允许保留的草稿不丢。
5. 五种宽度/文字条件下无空常驻详情栏、不可达主动作或被压缩的关键标签。
6. 换身份不闪现旧资料；断网/撤权/删除分别恢复；修复后不重复提交。
7. 发布前必须验证私聊/群组恢复、找联系人、未读与发消息不退化；若用户持续找不到人/群组，增加常驻通讯录快捷入口或调整导航。三个不是数量硬指标，不能为布局牺牲交流。
8. 产品验证比较旧四入口与新三入口的找人、群消息、新工作、找依据、看模型、待确认任务。采用新导航是设计决定，效率改善尚需测试证据。
9. compact Files 只出现一条模块 head，模块切换入口可达，文件树抽屉以可读展开态出现。
10. 退出登录后主壳消失，不继续显示原身份内容。
