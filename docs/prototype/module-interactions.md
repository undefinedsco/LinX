# Module Interaction Design

日期：2026-09-28。以 [R6](../../../homepage/docs/specs/personal-ai-product-experience-r6.md) RD01–12、F01–06 为跨模块合同；原 R4/R5 画板的四入口与固定四栏仅保留作历史参考。本文不新建资源、Task/Run、授权或训练权威。

## 信息架构与原入口迁移

| 一级入口 | 用户任务 | 既有能力与稳定重入 |
|---|---|---|
| 工作 | 和人/AI沟通、带上下文做事、推进持续任务 | Chat/Thread；新建会话、工作内通讯录与参与者详情保留 Contacts；当前材料、成果与待决定 |
| 知识 | 找到资料和经历、读来源、维护有条件的判断 | 原 Files 资源浏览、文件夹/预览/结构化表；最近、已确认、待整理、收藏是同资源视图 |
| 我的 AI | 改变方法、核对个人模型及评估/启用范围 | 方法与个人模型稳定进入；提供方、密钥和网络诊断仍是基础设置 |

Inbox 在头部汇总待决定；头像/菜单保留账号、服务、凭据、关于。个人联系人、Agent、群组仍是不同对象，联系人降为上下文入口不删除人与人沟通。收藏保留原引用与回跳，取消不删源、不确认知识、不授权训练。

旧 Chat/Files/Contacts/Favorites 深链由壳层兼容表定位原对象和新导航上下文；不为名称变化重建资源 URI、模块数据或权限。

## 第一屏与工作面

首次打开“工作”可直接开始，老用户恢复上次合法对象及允许保留的草稿。根据任务需要显示工作列表，主区可以是沟通、长成果、来源或比较；详情按需打开，默认没有空第三栏或固定助手名片。赐名、头像、Agent home、Repository 细节不抢主任务。

窄窗切换到当前阅读/决定面并给明确返回；不把所有列挤小。返回恢复会话位置、搜索范围、所选对象和输入。普通聊天不自动产生 Issue/Task 或一整套运行仪表盘。

## 一起做事与纠正

1. 输入目标，加入“本次材料”，核对引用与读取状态。
2. 执行中按事实显示阶段、实际引用、等待人与可用控制；模型/Agent/工具编排不假装为人类消息。
3. 用户修正先影响本次工作；可选择仅此次、保留知识草稿或明确确认有范围的经验。
4. 知识对象展示原话与系统提炼、来源、条件/例外；拒绝保留不影响继续工作。
5. 保存成果明确对象、空间与持久化结果；消息归档、成果保存、知识确认和训练授权分别呈现。

工具入口须有实际消费能力；失败材料可单独重试/排除，结果未知先恢复原请求，不重发已完成部分。具体合同见 [Chat/Secretary](module-chat-secretary.md)。

## 知识的阅读、搜索与使用

“知识”承接原 Files；普通文件按文件阅读，判断对象按人类可读内容、来源与条件呈现。显式打开结构化原文件时保留 Table；Raw/Kanban/Whiteboard 是适合任务时的投影，不因存在 renderer 就常驻。

搜索显示范围/覆盖，结果区分原记录、派生摘要、已确认/冲突/撤回知识；读取失败和索引未覆盖不等于全空间无资料。用户从结果检查来源后引用到当前工作，引用保留同一资源与版本，不复制成另一份知识。

修改形成既有 proposal，保留原值和建议；一次决定使用一处提交。冲突、失败、无权限均有恢复。详细字段和专业浏览边界见 [Files](module-files.md)。

## 方法、个人模型与训练

工作上下文与“我的 AI”打开同一方法/模型对象。方法显示本次/默认范围、继承、版本、能力与例外；保存不扩大资料权限，也不立即替换在途运行的配置。

个人模型按材料授权→真实任务→候选产物→独立评估→按范围启用/回退推进。未训练或协议未接通时准确说明状态，方法/知识仍可用。配置、部署、加载、Run 实际使用分别报告。个人模型本次未应用时按 R6 F04 提供停止、原版本修复或获准基础模型继续，不能静默回退后声称已使用个人模型。不得把训练藏回低频 provider 设置，也不得用空成长仪表盘催促训练。领域流程由 Foundry 负责。

## 等待、决定与长任务

当前工作 inline 和 Inbox 使用同一请求；输入、执行批准、认证、知识确认与训练授权不可合并。auto 控制谁推进，不改变 backend approval/grant。一次允许与长期 grant 是不同决定。

工作内任务视图从“新建任务/将工作设为持续任务”进入触发、范围、执行身份、下次时间的核对；详情可改定义、暂停未来触发和看最近 Run，纯人际聊天不需 Task。时区、错过与重叠运行由任务 owner 决定，未定不在前端猜测。

Task 是定义，Run 是一次执行，RunStep 是事实；等待输入回同一 Run，取消请求和已停止分开。关闭界面不停止工作；worker 完成不等于任务验收。重试说明是否会产生新一次执行及重复影响。见 [Inbox](module-inbox-approval.md) 与既有任务合同。

## 跨产品与来源返回

来源/索引问题进入 Xpod 相应空间控制，模型不可用进入对应 AI 用途，运行依赖失败进入服务诊断；带对象和明确原因，不复制后台管理产品。修复返回原决定并重读权威，身份、资料/费用/外发条件变化时重新展示差异。恢复连接不自动训练、不重建 Key/空间、不重做已完成动作。

回跳遵守当前权限；撤权不能回显快照。保留允许保留的草稿、筛选和位置，秘密不进入通用导航 URL。见 [场景恢复](../scene-restoration-solid-modeling.md)。
